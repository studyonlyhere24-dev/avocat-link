## 🚀 Deployment Instructions

### 1. Connect to Vercel

```bash
# Install Vercel CLI (optional for local testing)
npm install -g vercel

# Deploy from your Git repository
# Go to https://vercel.com and connect your GitHub/GitLab/Bitbucket repo
```

### 2. Set Environment Variables

In your Vercel project dashboard, add these environment variables:

| Variable | Value | Source |
|----------|-------|--------|
| `VITE_SUPABASE_URL` | Your Supabase Project URL | [Supabase Dashboard](https://app.supabase.com) |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Your Supabase Anon Key | [Supabase Dashboard](https://app.supabase.com) |

**Note**: These keys are safe to expose on the frontend (public keys). Private keys should never be committed to the repository.

### 3. Deploy

```bash
# Option A: Push to Git and let Vercel auto-deploy
git push origin main

# Option B: Manual deployment with Vercel CLI
vercel --prod
```

### 4. Verify Deployment

1. **Check build logs** in Vercel dashboard
   - Build should complete in ~2-3 minutes
   - Look for: "✅ Post-build: Generated dist/client/index.html"

2. **Test the deployed app**
   - Navigate to your Vercel domain
   - Verify routing works (TanStack Router)
   - Test Supabase integration (login, data fetching)

3. **Check console for errors**
   - Browser DevTools → Console tab
   - Verify no 404 errors for assets

## 🔒 Security Features

The updated `vercel.json` includes:

### Security Headers
```
X-Frame-Options: DENY                          # Prevent clickjacking
X-Content-Type-Options: nosniff                # Prevent MIME sniffing
Referrer-Policy: strict-origin-when-cross-origin # Control referrer info
```

### Caching Strategy
- **Assets** (`/assets/*`): 1 year cache (immutable)
- **HTML/Routes**: No cache (always fresh)

### Redirects
- Blocks direct access to Cloudflare config files (wrangler.json → 404)

## 🐛 Troubleshooting

### Build Fails with "Cannot find module"
```
✗ rm -rf node_modules
✗ npm install
✗ npm run build
```

### 404 Errors on Routes
- Verify `vercel.json` rewrites are correct
- Check that `dist/client/index.html` exists
- Verify post-build script ran successfully

### Supabase Connection Issues
- Confirm environment variables are set in Vercel
- Check Supabase RLS policies allow public anon access
- Verify CORS settings in Supabase

### CSS Not Loading
- Inspect network tab in DevTools
- Verify asset paths are correct (`/assets/styles-*.css`)
- Check caching headers
